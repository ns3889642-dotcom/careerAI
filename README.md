# 🚀 CareerAI

### AI-Powered Resume Analyzer & Career Guidance System

CareerAI is a Python-based web application that analyzes
resumes, extracts skills, matches job descriptions and
recommends suitable career paths.

## ✨ Features

- Upload resume in PDF format
- Automatic skill extraction
- Resume analysis
- Job matching percentage
- Matched skills identification
- Missing skills identification
- Career recommendations
- Skill coverage visualization

## 🛠️ Technologies Used

- Python
- Streamlit
- PDF Processing
- Text Similarity
- Git and GitHub

## 📂 Project Structure

- app.py
- resume_parser.py
- skill_extractor.py
- job_matcher.py
- career_recommender.py

## ▶️ How to Run

1. Clone the repository.
2. Install required dependencies:

   pip install -r requirements.txt

3. Run the application:

   streamlit run app.py
